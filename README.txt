ЛІГА ПУЕТ — пакет для розміщення на вебсервері
Збірка: 2026-10-07 (версія сторінки 27)

ЩО ЦЕ
Статичний сайт: одна сторінка index.html, дані (data/) і модулі (modules/).
Серверного коду й бази даних немає. Підійде будь-який вебсервер (Apache, nginx, IIS) або статичний хостинг.

ЯК РОЗМІСТИТИ
1. Скопіюйте ВЕСЬ вміст цієї теки в кореневу теку сайту або в підтеку (наприклад /liga/), зберігши структуру:
     index.html
     data/      (10 файлів)
     modules/   (2 файли)
2. Сайт має відкриватися через https:// (або http://), а не як файл із диска:
   довідник закладів data/insts.json завантажується запитом і з file:// не працює.
3. Сервер має віддавати файли в кодуванні UTF-8 і бажано зі стисненням gzip:
   без стиснення пакет важить ≈ 6,7 МБ, зі стисненням — у кілька разів менше.
   Для Apache вже є .htaccess; для nginx — приклад у nginx-example.conf (сам файл на сайт викладати не потрібно).
4. Після оновлення файлів попросіть користувачів оновити сторінку (Ctrl+F5).

ВАЖЛИВІ ОБМЕЖЕННЯ ЦІЄЇ ЗБІРКИ
- Дані зберігаються лише в браузері користувача (localStorage). Акаунти, результати й історія НЕ передаються
  на сервер: учень не побачить свій профіль з іншого пристрою, учитель не побачить результатів учнів,
  рейтинг між учасниками не спільний. Очищення даних браузера стирає профіль.
  Для спільної роботи потрібна серверна частина (база даних і вхід) — це окремий етап за технічним завданням.
- На сторінці входу є блок «Демо-акаунти для перегляду ролей» (пароль demo), зокрема адміністратор.
  Вони потрібні для показу; перед роботою з реальними учнями їх слід прибрати.
- Вхід через Google не налаштовано (потрібен ідентифікатор клієнта Google для вашого домену).
- Шрифти завантажуються з fonts.googleapis.com; без доступу до нього сторінка працює із системними шрифтами.
- Симулятор вступу: заклади знеособлені, їхні показники модельні (див. вкладку «Правила 2026»).
